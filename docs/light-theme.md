# Softer light theme

The light palette uses warm gray rather than white for large areas: page background #D9D6CE, cards and reading panels #E9E6DE, and inset surfaces #CECABF. Code and graph backgrounds are softened too. Dark-theme colors retain their existing values.

Secondary text and captions are darker to preserve legibility. Indigo links, green status text, red errors, and code syntax colors were adjusted for the new backgrounds. Amber button fills remain bright; separate amber text tokens keep badges and warning labels legible without changing button styling. Inputs have a stronger outline than decorative card borders.

Contrast measurements cover main/secondary/muted text and semantic/link colors on the three neutral surfaces, badge text on its tinted background, button labels, code labels and syntax colors. The lowest contrast among the three body-text tokens on neutral surfaces is 4.67:1. Input outlines measure 3.64:1 against their surface. These are palette checks, not a full accessibility certification or a guarantee for author-supplied images or custom content.

Visual review used an isolated catalogue, contact page and lesson preview with real components, simulated data and fallback fonts. The lesson sidebar and objectives callout retain their visual hierarchy. No saved course content, account behavior or database changes are involved.
